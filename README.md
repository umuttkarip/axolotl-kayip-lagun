# AXOLOTL — Kayıp Lagün

Türkçe su altı tarayıcı macerası. Üç bölge, dost kurtarma, baloncuk saldırıları ve bölüm sonu karşılaşması.

WASD veya ok tuşları: yüzme. Boşluk: baloncuk saldırısı. Shift: atılma. P: mola. Telefonlarda ekrandaki kontroller kullanılır.

Bu depo yalnızca herkese açık oyun dosyalarını içerir. GitHub Pages yayın kaynağı main dalının kök klasörüdür.
