# AXOLOTL — Kayıp Lagün

Türkçe su altı tarayıcı macerası. Üç bölgeyi keşfet, ışık incilerini topla, dostlarını kurtar ve derinliğin koruyucusuyla yüzleş. Güç seçimleri ve ayrı 60 saniyelik akıntı modu içerir.

Oyunu aç: https://umuttkarip.github.io/axolotl-kayip-lagun/ . Oyuncunun hesap açması veya giriş yapması gerekmez.

WASD veya oklarla yüz, Boşluk ile baloncuk at, Shift ile atıl; P veya Escape ile mola ver. Telefonlarda ekrandaki kontrolleri kullan. Ses isteğe bağlıdır. En iyi puan bu tarayıcıda saklanır.

Bu depo yalnızca herkese açık oyun dosyalarını içerir. GitHub Pages yayın kaynağı main dalının köküdür. Önceki deneysel hikâye kaynakları korunur; aktif oyun ana sayfadaki üç bölgeli sürümdür.
